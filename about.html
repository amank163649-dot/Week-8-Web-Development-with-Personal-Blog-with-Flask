About This Blog

Welcome! This is a personal blog built with Flask, demonstrating a full-featured web application with user authentication, blog post management, and a commenting system.

This project was built to practice:

  • Flask application factory pattern & blueprints
  • SQLAlchemy models and relationships
  • Secure authentication with Flask-Login
  • Jinja2 templating and Bootstrap-based responsive design
  • Form handling and validation with Flask-WTF
